# 🎨 Drawing App

Ứng dụng vẽ tự do đơn giản cho phép người dùng sáng tạo trực tiếp trên màn hình với các công cụ cơ bản.

## 🚀 Tính năng chính

* ✏️ Vẽ tự do trên canvas
* 🎨 Chọn màu vẽ
* 🧽 Tẩy (eraser)
* ↩️ Hoàn tác (undo)
* 💾 Lưu ảnh dưới dạng PNG

## 🛠️ Công nghệ sử dụng

* Frontend: HTML, CSS, JavaScript *(hoặc Flutter/Android tùy project)*
* Canvas API để xử lý vẽ

## 📱 Mô tả hoạt động

Người dùng vẽ trực tiếp bằng chuột hoặc cảm ứng → chọn màu → chỉnh sửa nét vẽ → lưu lại thành ảnh.

## 📌 Mục tiêu

Xây dựng một ứng dụng vẽ đơn giản, dễ sử dụng, phục vụ học tập và giải trí.
